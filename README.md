# CAHSE Framework

> **Coding Agent Harness for Software Engineering Self-Evolution**  
> 面向长程软件工程任务的智能体执行与自进化框架

CAHSE is a coding-agent harness that captures real software-development trajectories, reconstructs benchmark-style task experiences, and exports them as SkillOpt-compatible data for agent self-evolution.

CAHSE 是一个面向长程软件工程任务的智能体执行与自进化框架：它从真实开发轨迹中采集行为证据，后验重建任务问题与解法，并导出为可传入 SkillOpt 的结构化经验样本。

## Highlights

- Real coding trajectories as the source of experience.
- Benchmark-style task records inspired by SWE-bench, Defects4J, and BugsInPy.
- Post-execution synthesis of problem statements, solution evidence, changed files, and validation signals.
- Task taxonomy for normalized labels, unknown-task clustering, and human review.
- SkillOpt-compatible export for replay, judging, reflection, and validation-gated self-evolution.
